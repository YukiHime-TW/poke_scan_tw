# Play Console — 內容分級問卷（IARC）答案

應用程式類型：選「**工具／生產力／通訊**」或「**參考資料**」（非遊戲）。
內容分級問卷是是非題，依實際內容作答如下。

| 主題 | 答案 |
|---|---|
| 暴力（寫實／卡通／幻想）| 無 |
| 血腥 | 無 |
| 性與裸露 | 無 |
| 粗俗語言 | 無 |
| 受管制物質（毒品、酒精、菸草）| 無 |
| 賭博（寫實賭博、模擬賭博）| **無**（純收藏／組牌，無下注、無轉蛋、無戰利品箱）|
| 恐怖驚悚 | 無 |
| 使用者可否互相通訊 / 分享內容 | **否**（目前沒有聊天、沒有使用者對使用者功能）|
| 是否分享使用者位置 | 否 |
| 是否可分享個人資訊給其他使用者 | 否 |
| 應用程式內數位購買 | **否** |
| 是否顯示不宜兒童的廣告 | 否（無廣告）|
| 使用者原創內容且未經審核可公開 | 否 |

**預期結果**：所有地區「適合所有年齡層」／PEGI 3／ESRB Everyone。

> 若日後加入面交配對或聊天功能，需回來重新作答「使用者可互相通訊」與
> 「分享位置」兩題，分級可能上升。
