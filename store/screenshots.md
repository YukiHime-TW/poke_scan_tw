# Play 商店截圖 — 拍攝清單

## 規格

- 手機截圖：**至少 2 張**，建議 **4–8 張**
- 直向，建議 1080×1920 或 1080×2340（9:16 ~ 9:19.5）
- PNG 或 JPG，每邊 320–3840px
- 不要加外框、假手機殼、行銷文案在圖上（Play 不喜歡；純畫面即可）
- 用實機或模擬器：`flutter run --release` 後截圖

## 建議畫面（依這個順序，第 1 張最重要）

1. **收藏主畫面** — 展開一個系列，看得到彩色／黑白卡、完成度進度條、左上角持有數
2. **相機掃描** — 掃描畫面，紅框對準卡片左下角編號（可擺一張實體卡進去）
3. **篩選面板** — 點漏斗打開底部面板，屬性那排色點 chip 展開
4. **牌組編輯** — 編輯模式，上方青色條，卡片顯示「放入牌組數」與庫存比對標籤
5. **牌組清單 / 匯出** — 牌組列表，或「複製」出來的對齊牌表文字
6. **卡片用途** — 非編輯模式點一張卡，「用於 N 副牌」的查詢結果

前 3 張就能過門檻；有 5–6 張 listing 比較完整。
